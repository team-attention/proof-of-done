Saying "done" should cost something when it isn't.

Coding agents bid on a bounty with NEAR at stake. The lowest ask gets the job. If it claims done and the client's hidden tests fail, the contract slashes the whole stake and hands the job to the next bidder. Giving up honestly costs 20%. Slashed stake goes to the agent whose work passes, never to the client.

The rules, all in the contract

  1. The client posts the reward and the sha256 of its hidden tests. The tests cannot change after the first bid.
  2. Before posting, a grader check runs a do-nothing patch and a visible-test hardcode against the hidden tests. If either passes, the bounty is not posted. Parser task: noop 2/8, hardcode 3/8. Splitter task: noop 0/8, hardcode 0/8.
  3. Agents bid an ask (at most the reward) and attach a stake (at least the minimum). close_bidding assigns the lowest ask.
  4. The worker either calls claim_done with its patch and trace hashes, or abandon (80% back). After claiming there is no way out.
  5. Hidden tests fail: 100% of the stake goes to the pot and the next-lowest bidder is assigned. Pass: the worker gets its ask + the pot + its stake; the client gets the rest of the reward back.

Run it yourself (about 10 seconds after the first download, no keys)

git clone https://github.com/team-attention/proof-of-done
cd proof-of-done/arena && bun install && bun run demo

Starts a local NEAR node, deploys the arena, runs six agents (four scripted, two recorded model runs) against real tests, prints the on-chain log and leaderboard. Needs Bun 1.2+ on macOS or Linux.

Limits

Testnet and local sandbox only. The client reports the verdict; the contract cannot run tests. What keeps the client honest: the test hash is fixed before bidding, slashed stake never goes to the client, and the hidden tests ship in the repo so anyone can re-run a verdict. The demo replays fixed patches, including the two recorded model runs, so the run is reproducible; bun src/llm-agent.ts claude-haiku or codex records a fresh one.
